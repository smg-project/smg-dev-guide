---
description: Record a lesson when a skill or recipe in this guide was wrong
---
1. Read `skills/learn/SKILL.md`.
2. Capture the evidence while you have it: the recipe line, the command and its output, the SMG commit (`git rev-parse HEAD`), and what is true now.
3. File it as a GitHub issue labelled `lesson` on smg-project/smg-dev-guide (`gh issue create --label lesson ...`), or write `lessons/YYYY-MM-DD-<slug>.md` from `lessons/TEMPLATE.md` when `gh` is unavailable.
